QR LOVE LETTER WEBSITE

This is the webpage that should open when the QR code is scanned.

GitHub Pages:
1. Create/open the repository for this QR code.
2. Upload index.html into the ROOT of that repository.
3. Enable GitHub Pages.
4. Your QR code should point to that repository's GitHub Pages URL.

The QR graphic itself remains QR-only. The letter appears on the webpage after scanning.
